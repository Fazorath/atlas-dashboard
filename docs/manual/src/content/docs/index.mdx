## Start in five minutes

A fresh install turns on only **Weather** and **Habits**, the two Modules that need no account. Everything else is a line you uncomment in one YAML file when you are ready.

## What it is not

<CardGrid>
	<Card title="Not a hosted service" icon="laptop">
		Atlas runs on your own machine. Nothing leaves it except the requests each Module makes to its own Source.
	</Card>
	<Card title="Not behind a login (yet)" icon="warning">
		Atlas has no accounts. Keep it on loopback and put a reverse proxy with auth, or a private network such as Tailscale, in front of it.
	</Card>
</CardGrid>
